# Tugasku: Task Management App

This is a simple and interactive Todo List application built using **React** and **Tailwind** to helps users manage their daily tasks efficiently. Users can create, edit, complete, delete, search, and sort tasks based on various criteria such as deadline, creation time, and more.

Features
- Add Task – Add new tasks to your list
- Edit Task – Update task name or deadline
- Complete Task – Mark tasks as completed
- Delete Task – Remove tasks from the list
- View Active Tasks – See all ongoing tasks and manage them (edit, complete, delete)
- View Completed Tasks – View tasks that have been finished
- Sort Tasks – Sort tasks by Name, Created time, Deadline, Completed time, and Last edited time
- Search Tasks – Find tasks using keywords
